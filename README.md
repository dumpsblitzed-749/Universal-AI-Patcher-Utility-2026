## FAQ

### Is OmniPatch safe to use?

OmniPatch runs entirely locally on your Windows machine. It does not collect data, connect to external servers, or contain any malicious code. All modifications are performed offline.

### Which AI applications are currently supported?

OmniPatch supports ChatGPT (Plus/Team), Claude (Pro), Perplexity (Pro), Microsoft Copilot (Pro), Cursor (Pro), GitHub Copilot, Devin AI, and JetBrains AI Assistant (Pro). Future updates will aim to add more.

### How often is OmniPatch updated?

We strive to release updates within 48 hours after any of the supported AI applications undergo significant changes or security updates that affect the patching mechanism.

### Will this work on my Windows version?

OmniPatch is designed for Windows 10 and Windows 11 (64-bit). Compatibility with older versions is not guaranteed, and macOS or Linux are not supported.

### Do I need an existing account for these AI services?

For most applications, yes. OmniPatch activates premium features on an existing account. Some tools may require you to sign in once after patching for the changes to take effect.

### Can I revert the changes made by OmniPatch?

Yes. OmniPatch includes an option within its interface to cleanly revert all modifications, restoring the applications to their original state.

### Does running OmniPatch require an internet connection?

No. The entire activation process is performed offline. An internet connection is only needed initially to download the patcher and, in some cases, to sign into your accounts.

### Will this affect future updates of the AI apps?

App updates may reset the patch, requiring you to re-run OmniPatch. We monitor updates and will provide guidance if a new patch is needed.
